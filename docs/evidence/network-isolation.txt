=== COMPOSE EQUIVALENT (verified, for contrast) ===
Both compose.yaml and compose.prod.yaml define:

  network edge:     driver bridge, internal=false
  network internal: driver bridge, internal=true

  postgres -> ['internal']      redis   -> ['internal']
  backend  -> ['edge', 'internal']
  frontend -> ['edge']

So in Compose the frontend is attached only to `edge` and has no route to
`internal`, where Postgres lives. That segmentation is real and works; it is
simply not reproduced in the Kubernetes manifests.
